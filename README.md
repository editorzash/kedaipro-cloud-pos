# KEDAIPRO — Smart Culinary & Warkop POS OS

**KEDAIPRO** adalah sistem kasir (*Point of Sale*) multi-layar canggih yang dirancang untuk kedai modern, warkop 24 jam, cafe bistro, dan restoran. Memadukan estetika *Dark Titanium* dengan fitur operasional terpadu: **Kasir POS**, **Denah Meja 2D Interaktif**, **Kitchen Display System (KDS)**, dan **Simulasi Struk Thermal 58mm**.

---

## 🚀 Fitur Unggulan KEDAIPRO

1. **Dual Visual Theme (Dark Titanium & Crisp Light)**:
   - Dukungan tema gelap (*Dark Mode*) berlatar slate pekat dengan aksen emerald & amber, serta tombol pengganti tema instan di bilah atas.

2. **Denah Meja Interaktif (*Floor Plan*)**:
   - Visualisasi denah meja (Meja 01 s/d Meja 12, Area Bar, Sofa VIP).
   - Indikator status warna real-time:
     - 🟢 **Tersedia (Kosong)**
     - 🟡 **Sedang Makan** (lengkap dengan durasi menit berjalan)
     - 🔴 **Menunggu Pembayaran (Billing)**
   - Mengetuk meja mana pun langsung membuka atau membuat pesanan untuk meja tersebut.

3. **Kitchen Display System (KDS)**:
   - Tiket pesanan terhubung langsung ke dapur.
   - Status pengerjaan hidangan: *Mulai Masak* ➡️ *Siap Diantar* (dengan efek suara lonceng dapur).

4. **Dialog Varian & Modifier Menu**:
   - Pilihan tingkat kepedasan (Level 0 s/d Level 3 🔥).
   - Pilihan tambahan topping (Telur Mata Sapi, Keju Parut, Kornet Daging).
   - Kolom catatan khusus koki dapur.

5. **Simulasi Struk Kasir Thermal 58mm**:
   - Tampilan kertas struk dengan font monospace, gerigi sobekan kertas, barcode, dan rincian lengkap.
   - **🖨️ Cetak Struk**: Format cetak printer thermal 58mm.
   - **📲 Kirim WhatsApp**: Salin dan kirim langsung ke nomor pelanggan.

6. **Bagi Tagihan (*Split Bill*)**:
   - Fitur perhitungan bagi rata tagihan (2 s/d 5 orang) memudahkan pelanggan saat nongkrong rame-rame.

7. **Audio Taktil & Shortcut Keyboard**:
   - Efek suara klik, lonceng pesanan dapur, dan laci kasir lunas (*Web Audio API*).
   - Tombol cepat keyboard standar kasir:
     - `F1`: Kasir POS
     - `F2`: Denah Meja
     - `F3`: Kitchen Display
     - `F9`: Bayar Cepat
     - `ESC`: Tutup Dialog
